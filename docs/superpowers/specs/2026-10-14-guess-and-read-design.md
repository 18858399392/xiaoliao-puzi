# 猜一猜与精选短读

用户已同意 2026-10-14 调研建议与实施顺序。本轮完成第一阶段：猜一猜和精选短读，延续已批准的黑色信息流、设置内分类、默认搞笑段子、统一收藏与离线缓存。搜书和音乐工具按后续阶段单独处理。

- 猜一猜：本地精选题目，包含谜语、字谜、急转弯及逻辑趣题；题面、类别可见，答案和解释仅主动揭晓。展示记录和揭晓记录独立，刷新、主题切换及喜欢页面不会丢失已揭晓状态。
- 短读：卡片含标题、作者、简介、阅读时间；点击打开完整阅读面板，保留段落、出处和许可。退出回到原信息流位置，重新打开可继续阅读。采用明确标记公有领域的经典文章，项目编写的导语与说明清楚标明；不引入网络小说或漫画。
- 新分类位于“我的→内容分类”，不恢复顶部分类条。新卡片沿用现有字体、主题与爱心动效；文章面板可用返回、Escape、键盘焦点操作。
- 本地静态模块存全部新增文字，不添加账户、付费接口或 API 密钥。离线壳包含新数据、样式及脚本；独立 HTML 和 ZIP 同步更新。
- 收藏保存完整条目快照，保留旧文字与音乐收藏。复制谜题时不泄露尚未揭晓的答案。
- 验收：新分类可打开、答案隐藏/揭晓/保持、正文与续读、收藏重开、320/390/1280px 不溢出、黑色与笔记本主题、旧段子与音乐首屏、离线重开。

来源范围有明确依据后才打包；仅供学术的数据集不纳入。首批数量以经过数据完整性与内容审校的最终库为准，不用同题换数字充数量。

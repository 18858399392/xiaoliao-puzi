# 笑料铺子界面精修

用户已确认保留原黑色信息流，并限定本次只优化深色视觉、点赞动画、设置排布和笔记本模式。首页不加标题栏或分类栏，分类继续位于设置，新浏览器默认搞笑段子。已有分类偏好、喜欢记录、字体和主题色继续兼容。

深色使用近黑底色 #080a0c、设置面板 #11151a、边线 #252c33、正文 #e7e9ea、辅助字 #8b98a5 和原蓝色 #1d9bf0；信息流保留无缝细分隔线、图标操作和原底部导航，不增加文字操作按钮。

点赞采用自绘 SVG 空心轮廓及从下到上显露的粉色渐变填充，配合约 0.55 秒的小幅回弹、细环及七组小粒子。动画仅在用户添加喜欢时播放，重建卡片和恢复已有喜欢时不播放；取消喜欢立即停止，系统减少动态效果时仅更新填充。文字和音频喜欢共用效果，不修改播放流程。

设置显示简短页名，按我的喜欢、内容分类、阅读外观、主题色、浏览统计分组；采用统一行高、间距、圆角和选择状态。字体列表收进原生可折叠区域，摘要显示当前字体。字号按钮统一为减/增且极值禁用。四个主题使用小型实际样式预览，保留原全部选项及存储键。

笔记本采用较浅的自然纸色、极淡纤维纹理、细蓝灰横线、淡红双页边线和折页阴影。横线周期与正文行距共用变量，卡片上下空间及操作区域按整行分配，避免跨卡片横线错位；最大字号也同步放宽行距。设置页取消横线底纹，以保证表单清晰。

保持单文件 HTML/CSS/JavaScript 架构。只修改 index.html 中相关视觉、SVG、动效和设置状态；API、错误处理、加载策略、播放逻辑、导航行为及清空喜欢行为均不在本次变更内。

验证：四主题在 320/390/768/1280 像素下无横向溢出；14/17/24 字号的纸张线距；喜欢/取消/快速重复点击、已有喜欢刷新、主题重建、音频收藏和减少动态效果；设置分类、字体、字号、主题色的选中与持久化；真实接口另做首屏检查，不以模拟内容冒充真实加载。

# 两个资源搜索入口

用户已确认：加入 PanSou 与 PanSearch 两个入口；使用插件搜索，关闭 Telegram 频道来源；不建立文件资源库，结果可站外打开。该确认覆盖之前移除外链的要求，仅对本次资源搜索新增出口。

在“我的”增加“资源搜索”分组，分别为 PanSou 盘搜、PanSearch 网盘搜索。PanSou 使用公开演示实例的搜索 API，固定 src=plugin；只展示明确标记 plugin: 且属于受支持网盘域名的 HTTPS 分享链接，排除 Telegram、推广及脚本地址。正文和现有歌曲保持无站外导航。

PanSearch 使用其自身搜索页 /search?keyword=，通过用户输入关键词后显式点击打开站外；它没有已确认的公开接入 API。不能声称控制其站外内部来源，也不嵌入其推广。PanSou 支持在公共接口失败时站外打开插件模式搜索，需先验证参数确实设置插件来源，未经验证不能加入该后备链接。

搜索面板沿用黑色/纸张主题，支持返回、Esc、键盘提交、移动端宽度。结果显示标题、网盘、提取码、复制和打开。缓存最近十组查询元数据二十分钟，不下载文件。超时与断网显示可重试状态，关闭或新查询取消旧请求，不能覆盖新结果。

公共服务可能限流或停止，不承诺任意作品有结果，不把空列表描述成已接入成功。验证真实 API 查询、链接参数、Telegram 过滤、过期请求、复制、320/390/1280 宽度以及已有阅读/歌曲保留。发布沿用现有 GitHub main 与 Cloudflare Pages 直接部署，并核对正式域名及提交。

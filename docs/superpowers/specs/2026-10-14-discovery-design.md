# 已同意的后续阶段：搜书与歌曲工具

延续用户已同意的调研建议，在首阶段猜题/短读上线后继续实施：

- 我的页新增“找一本书”，输入书名、作者或 ISBN。提供微信读书、Open Library、Google 图书、维基文库的搜索入口和国图入口；Open Library 返回的书目单独显示真实版本信息。未确认的外站入口只称“去搜索”，不伪称已有全文。排除明确的漫画、玄幻、修仙及小说类结果；无结果也保留来源入口。
- 听听新增“找一首歌”。沿用网易云社区查询和 Audius；在独立搜索面板展示结果，不打乱默认先十六首唱鸭的顺序。每次搜索有超时、可取消的过期结果隔离、来源错误提示；不申请付费密钥。
- 播放器加下一首，播完沿当前列表继续；同一时间仍仅有一个播放器。搜索结果可以播放与收藏。
- 下载入口区分明确允许下载的作品与原站查看。优先 Audius 的下载允许字段，尊重下载访问条件；其他来源不把播放链接伪装成下载许可。另提供 Jamendo、FMA、Musopen、Bandcamp 原站入口，不宣称这些平台已全部成为本站 API。
- 用同一原生对话框和原有主题变量，保留键盘操作、手机宽度及已有离线内容。不新增第三方账户、付费、批量音频下载或书籍全文抓取。

实施清单：新增 discovery.js/css；扩展 MusicSources.search；在 index.html 插入入口并扩展 Player.next；把新模块纳入离线壳及独立 HTML；验证搜索响应、空/失败状态、版本与许可标记、下一首、旧的离线猜题/阅读；提交发布并确认正式域名。

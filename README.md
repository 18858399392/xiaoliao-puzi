# 笑料铺子

手机优先的段子与音频信息流。文字直接读取完整本地库，音频先显示本地片段、再通过网络补充。

[在线访问](https://18858399392.github.io/xiaoliao-puzi/)

## 功能

- 随机文字内容、音频片段与分类浏览。
- 喜欢列表、文字复制与本地缓存。
- 明暗及特色阅读主题，支持字体与字号调整。

喜欢列表、阅读记录和设置保存在当前浏览器。现有 396 条不同段子、200 条冷笑话、3386 条一言全部随项目保存。正文约 0.30 MB，含分类、编号的文字数据约 0.56 MB；整个 starter-content.js 约 0.60 MB（不含 MP3）。文字浏览不调用 API，歌曲继续使用本地片段与随机接口，远程音频链接可能过期。

HTTPS 网站或 localhost 首次联网访问并完成后台页面缓存后，可以在同一浏览器断网重开，继续查看未展示的文字。网站后台以最多两个下载任务缓存默认启用的全部 16 个本地 MP3，共约 5.3 MB；下载完成后这些片段也能断网播放和拖动进度，不等待外部歌曲接口。页面先显示，歌曲下载在后台进行，单个下载失败可以在以后打开时重试。远程歌曲仍需联网。

首次从未打开过的网站仍需要网络；清除网站数据可能移除离线缓存。离线文字 HTML 内嵌文字和脚本，离线完整版 HTML 还内嵌全部 16 个歌曲片段，第一次打开就可离线阅读和听歌。外部特殊字体离线时使用系统字体，本地歌曲文件也随 ZIP 提供。

## 本地运行

在仓库目录运行 `python server.py`，访问 `http://localhost:8765/`。

`http://localhost:8765/content-review.html` 是本地首屏筛选页。勾选表示选入项目预置内容；剔除同时过滤后台返回的同一 ID。点击“应用到本地预览”保存所选内容，原包备份至 `.starter-backups/`；此操作不清除用户喜欢或浏览历史。独立 HTML 可导出和导入 JSON 选择包；静态公开站点不能直接写仓库文件。

`starter-content.js` 保存本地文字和歌曲信息，`starter-selection.json` 保存编辑选择（默认全选文字），`content-candidates.json` 是完整候选快照，`starter-audio/` 保存本地短 MP3。重新生成预置包可以运行 `python starter_data.py`，它使用已保存的选择，不会重置你的筛选结果，同时依据页面、数据、缓冲脚本和模板散列更新 offline-worker.js。编辑源码后也需要运行该命令，确保离线缓存版本更新。离线缓存更新后重新打开阅读页使用新版本。

文字在本地随机排序，缓冲不足时直接从本地库补充；歌曲接口保持随机获取。页面按 ID 过滤缓存、浏览历史及剔除列表；同一浏览器最多保留最近 10,000 个每类展示记录，换设备、隐私窗口或清除网站数据后记录不共享。文字全部展示后提示已读完，可以换分类，不自动清空历史重播。展示指卡片已加入信息流，包含屏幕下方内容。

项目以 HTML、CSS 和 JavaScript 实现，通过 GitHub Pages 托管。

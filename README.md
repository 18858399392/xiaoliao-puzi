# 精神零食

手机优先的段子与音频信息流。文字直接读取完整本地库，音频先显示本地片段、再通过网络补充。

[在线访问](https://18858399392.github.io/xiaoliao-puzi/)

## 功能

- 随机文字内容、音频片段与分类浏览。
- 喜欢列表、文字复制与本地缓存。
- 明暗及特色阅读主题，支持字体与字号调整。
- 猜一猜：250 道生活谜语、自然谜语、字谜和逻辑趣题，主动揭晓参考答案与解释。
- 精选短读：51 篇经典散文及文章，完整阅读面板、来源链接、收藏与阅读位置恢复。
- 找一本书：输入书名、作者或 ISBN，查看书目和微信读书、Open Library、Google 图书、维基文库、国图等入口；不收录明确的小说、玄幻和漫画结果。
- 找一首歌：独立搜索中文歌源和 Audius，不打乱默认唱鸭优先的信息流。播放器支持下一首与播完续播；来源明确允许下载的作品提供原站下载入口。

喜欢列表、阅读记录和设置保存在当前浏览器。现有 396 条不同段子、200 条冷笑话、3386 条一言全部随项目保存。正文约 0.30 MB，含分类、编号的文字数据约 0.56 MB；整个 starter-content.js 约 0.60 MB（不含 MP3）。文字浏览不调用 API。听听先显示已选本地唱鸭片段，随后接入网易云在线歌单（Meting 社区服务）和 Audius 非受限热门曲目；有些曲目为试听片段，第三方链接的可用性取决于来源。

HTTPS 网站或 localhost 首次联网访问并完成后台页面缓存后，可以在同一浏览器断网重开，继续查看未展示的文字。网站后台以最多两个下载任务缓存默认启用的全部 16 个本地 MP3，共约 5.3 MB；下载完成后这些片段也能断网播放和拖动进度，不等待外部歌曲接口。页面先显示，歌曲下载在后台进行，单个下载失败可以在以后打开时重试。远程歌曲仍需联网。

首次从未打开过的网站仍需要网络；清除网站数据可能移除离线缓存。离线文字 HTML 内嵌文字和脚本，离线完整版 HTML 还内嵌全部 16 个歌曲片段，第一次打开就可离线阅读和听歌。外部特殊字体离线时使用系统字体，本地歌曲文件也随 ZIP 提供。

## 本地运行

在仓库目录运行 `python server.py`，访问 `http://localhost:8765/`。

`http://localhost:8765/content-review.html` 是本地首屏筛选页。勾选表示选入项目预置内容；剔除同时过滤后台返回的同一 ID。点击“应用到本地预览”保存所选内容，原包备份至 `.starter-backups/`；此操作不清除用户喜欢或浏览历史。独立 HTML 可导出和导入 JSON 选择包；静态公开站点不能直接写仓库文件。

`starter-content.js` 保存本地文字和歌曲信息，`starter-selection.json` 保存编辑选择（默认全选文字），`content-candidates.json` 是完整候选快照，`starter-audio/` 保存本地短 MP3。重新生成预置包可以运行 `python starter_data.py`，它使用已保存的选择，不会重置你的筛选结果，同时依据页面、数据、缓冲脚本和模板散列更新 offline-worker.js。编辑源码后也需要运行该命令，确保离线缓存版本更新。离线缓存更新后重新打开阅读页使用新版本。

文字在本地随机排序，缓冲不足时直接从本地库补充。歌曲在本地卡片显示后后台补充在线曲目，按批次加入缓冲，多数来自中文歌单，穿插 Audius；来源请求有超时和失败冷却，不影响本地片段。页面按 ID 过滤缓存、浏览历史及剔除列表；同一浏览器最多保留最近 10,000 个每类展示记录，换设备、隐私窗口或清除网站数据后记录不共享。文字全部展示后提示已读完，可以换分类，不自动清空历史重播。展示指卡片已加入信息流，包含屏幕下方内容。

本地歌曲允许再次收听：重新打开时优先显示尚未展示的本地片段，再显示可重听的片段；同一次打开不重复添加同一个歌曲卡片。远程歌曲继续按历史去重。浏览过全部本地歌曲也不会把本地音乐入口变空，不需要清除浏览记录或喜欢。

在线卡片严格排在本次打开的全部本地唱鸭卡片之后，包括浏览器中已有在线曲目缓存的情况。此顺序指信息流排列，不要求逐首播放完才能继续滚动。新来源不批量下载或加入离线 MP3 缓存，作品卡片保留来源链接。`music-sources.js` 维护接入端点、曲目归一化和播放链接；新增脚本也包含在离线页面壳中。

项目以 HTML、CSS 和 JavaScript 实现，通过 GitHub Pages 托管。

## 本地阅读扩展

在“我的→内容分类”选择猜一猜或精选短读，选中后回到首页。新增文字由 `extra-content.js` 提供，目前约 0.25 MB；页面壳缓存完成后，这两个分类可离线使用。谜题展示历史与揭晓历史独立，已揭晓答案和文章阅读位置保存在当前浏览器；喜欢保存完整内容，不需要再次请求原站。

`tools/riddles.tsv` 保存项目编写与 AI 辅助整理的题面、答案及解释，不复制仅供学术的数据集。`tools/readings.json` 保存明确标记公有领域的维基文库文章及版本依据；`content-sources.json` 列出出处和许可。正文转录保留 CC BY-SA 4.0 许可和原作者，导读与去除异文、题跋等编辑处理在阅读页注明。

修改题库或文章后运行 `python tools/build-extra-content.py`，再运行 `python starter_data.py` 更新离线壳。重新从来源导入使用 `python tools/import-readings.py`，需要 Python 的 BeautifulSoup；日常构建仅用标准库，不需要联网。导入名单固定，不抓取整站。

## 多来源查找

`discovery.js` 处理用户主动发起的书目查询和歌曲搜索。Open Library 书目缓存七天，最近歌曲搜索元数据缓存二十分钟，最多保存二十组查询。外部链接的按钮分别写“去搜索”“检索入口”或“查看此书目”，不把有书目说成有免费全文。下载标记只来自作者明确允许且无下载门槛的 Audius 元数据，点击后去来源完成下载；Meting 播放链接不会自动变成下载按钮。新工具没有添加付费密钥、批量音频下载或书籍全文抓取。

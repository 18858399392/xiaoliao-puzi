# 笑料铺子

手机优先的随机段子与音频信息流。

[在线访问](https://18858399392.github.io/xiaoliao-puzi/)

## 功能

- 随机文字内容、音频片段与分类浏览。
- 喜欢列表、文字复制与本地缓存。
- 明暗及特色阅读主题，支持字体与字号调整。

喜欢列表、阅读记录和设置保存在当前浏览器。内容来自外部接口，音频链接可能过期。

## 本地运行

直接打开 `index.html`，或在仓库目录运行 `python -m http.server 8000` 后访问 `http://localhost:8000/`。

项目以 HTML、CSS 和 JavaScript 实现，通过 GitHub Pages 托管。

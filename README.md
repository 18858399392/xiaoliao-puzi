# 笑料铺子

手机优先的段子与音频信息流。首屏先显示项目预置内容，后台补充未展示的内容。

[在线访问](https://18858399392.github.io/xiaoliao-puzi/)

## 功能

- 随机文字内容、音频片段与分类浏览。
- 喜欢列表、文字复制与本地缓存。
- 明暗及特色阅读主题，支持字体与字号调整。

喜欢列表、阅读记录和设置保存在当前浏览器。预置文字和 MP3 在项目里，不依赖首次 API 请求；后台内容来自外部接口，后台音频链接可能过期。

## 本地运行

在仓库目录运行 `python server.py`，访问 `http://localhost:8765/`。

`http://localhost:8765/content-review.html` 是本地首屏筛选页。勾选表示选入项目预置内容；剔除同时过滤后台返回的同一 ID。点击“应用到本地预览”保存所选内容，原包备份至 `.starter-backups/`；此操作不清除用户喜欢或浏览历史。独立 HTML 可导出和导入 JSON 选择包；静态公开站点不能直接写仓库文件。

`starter-content.js` 保存已选内容及可请求编号目录，`starter-selection.json` 保存编辑选择，`content-candidates.json` 是完整候选快照，`starter-audio/` 保存本地短 MP3。重新生成预置包可以运行 `python starter_data.py`，它使用已保存的选择，不会重置你的筛选结果。

文字后台从已知未展示编号中随机挑选，并使用 `?id=` 获取；歌曲接口保持随机获取。页面按 ID 过滤缓存、浏览历史及剔除列表；同一浏览器最多保留最近 10,000 个每类展示记录，换设备、隐私窗口或清除网站数据后记录不共享。

项目以 HTML、CSS 和 JavaScript 实现，通过 GitHub Pages 托管。
